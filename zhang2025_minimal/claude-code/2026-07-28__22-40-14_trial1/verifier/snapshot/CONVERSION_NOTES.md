# Conversion Notes: IBL Brain-Wide Map to Neural Decoder Format

## Source Data

- **Dataset**: International Brain Laboratory Brain-Wide Map (BWM) release
- **Paper**: "A brain-wide map of neural activity during complex behaviour" (IBL, 2023)
- **Method**: "Exploiting correlations across trials and behavioral sessions to improve neural decoding" (Zhang et al., 2025)
- **Data**: Neuropixels recordings from 139 mice performing a visual decision-making task
- **Available sessions**: 354 of 459 total sessions available in local cache

## Processing Decisions

### 1. Temporal Alignment
- **Event**: Stimulus onset (`stimOn_times`)
- **Window**: -0.5 to 1.5 seconds (2.0 seconds total)
- **Source**: Reference code `0_data_caching.py` line 53: `'time_window': (-.5, 1.5)`

### 2. Time Binning
- **Bin size**: 20 ms
- **Number of bins**: 100 per trial
- **Source**: Reference code `0_data_caching.py` line 52: `'binsize': 0.02`
- **Source**: Methods paper: "divided into 20-ms bins, producing T = 100 time steps"

### 3. Neuron Selection
- **Filter**: Well-isolated neurons (cluster quality label >= 1.0)
- **Source**: Data paper: "Neurons generated by the spike-sorting pipeline were excluded... if they failed one of the three criteria: amplitude > 50 uV; noise cut-off < 20 uV; and refractory period violation"
- **Note**: The Zhang reference code uses qc=None (all clusters), but we apply quality filtering to match the BWM paper's decoding methodology and keep file sizes manageable. The quality label integrates the three criteria from the paper.
- **Expected average**: ~108 well-isolated neurons per probe (data paper)

### 4. Multi-Probe Merging
- **Method**: Merge spikes from all probes in a session, reindex cluster IDs
- **Source**: Reference code `ibl_data_utils.py:merge_probes()`
- **Rationale**: "data from the probes recorded in the same session are not statistically independent"

### 5. Brain Region Mapping
- **Atlas**: Beryl mapping from IBL atlas
- **Source**: Reference code `ibl_data_utils.py:list_brain_regions()` uses `acronym2acronym(..., mapping='Beryl')`

### 6. Trial Filtering
- **Reaction time**: 0.08 - 2.0 seconds
- **NaN exclusion**: stimOn_times, choice, feedback_times, probabilityLeft, firstMovement_times, feedbackType
- **No-choice exclusion**: Trials where choice == 0
- **Source**: Reference code `ibl_data_utils.py:load_trials_and_mask()` defaults

### 7. Behavioral Data Processing

#### Wheel Speed
- **Source**: Raw wheel position and timestamps
- **Processing**: Interpolate to 1kHz uniform sampling -> Butterworth filter -> velocity -> absolute value
- **Matching**: ibllib's `interpolate_position` and `velocity_filtered` functions
- **Discretization**: 3 equal-frequency bins (33rd and 67th percentiles per session)

#### Whisker Motion Energy
- **Source**: `leftCamera.ROIMotionEnergy.npy` (fallback to right camera)
- **Camera**: Left camera at 60 Hz, matching "whisker pad area" definition from data paper
- **Discretization**: 3 equal-frequency bins (33rd and 67th percentiles per session)

#### Behavior Interpolation
- **Method**: Linear interpolation to match neural bin times
- **Bin centers**: `linspace(t_beg + binsize, t_end, n_bins)`
- **Source**: Reference code `ibl_data_utils.py:get_behavior_per_interval()`
- **Quality check**: Trials excluded if behavior data doesn't cover the full interval

### 8. Decoder Inputs
1. **time_since_stimulus_onset**: Continuous, time-varying. Linearly spaced from -0.48s to 1.5s.
2. **trial_number_in_block**: Continuous, constant within trial. 0-indexed count from block start.

### 9. Decoder Outputs
1. **choice**: Binary (0=left, 1=right). Original data: -1=left, 1=right.
2. **prior**: Categorical 3-class. p(left)=0.2 -> 0, p(left)=0.5 -> 1, p(left)=0.8 -> 2.
3. **wheel_speed**: Categorical 3-class discretization of continuous wheel speed.
4. **whisker_motion_energy**: Categorical 3-class discretization of continuous whisker ME.

## Sanity Checks

### Check 1: Trial counts
- Data paper: "at least 400 trials" per session -> we observe 401-885+ raw trials
- After filtering (RT, NaN, no-choice): ~60-80% of trials retained (typical)

### Check 2: Neuron counts
- Data paper: "averaging 108 per probe" well-isolated neurons
- Our data: min=8, max=524, mean=178 per session (combining probes, well-isolated only)
- Consistent with expectations (higher mean due to multi-probe merging)

### Check 3: Block structure
- Data paper: "90 unbiased trials" then biased blocks of 20-100 trials
- Our prior distribution: ~15% at 0.5 (unbiased), ~43% at 0.2, ~42% at 0.8
- 90/~600 total trials ≈ 15% unbiased -> matches

### Check 4: Choice distribution
- Near 50/50 left/right split expected -> ~48/52 observed -> matches

### Check 5: Decoder performance
- All outputs above chance (sample data, 10 sessions):
  - Choice: 0.625 balanced accuracy (chance: 0.500)
  - Prior: 0.662 balanced accuracy (chance: 0.333)
  - Wheel speed: 0.576 balanced accuracy (chance: 0.333)
  - Whisker ME: 0.563 balanced accuracy (chance: 0.333)

### Check 6: Time bins
- Methods paper: "20-ms bins, producing T = 100 time steps"
- Our data: T=100 for all trials -> matches

### Check 7: Alignment window
- Methods paper: "align trials to the stimulus onset, considering neural activity from 0.5 s before to 1.5 s post-onset"
- Our window: (-0.5, 1.5) -> matches

## Known Limitations

1. **354 of 459 sessions available**: 105 sessions not in local cache
2. **Quality filtering applied**: Only well-isolated neurons (label >= 1.0) included, matching BWM paper methodology but differing from Zhang reference code which uses all clusters
3. **Discretization**: Wheel speed and whisker ME discretized per-session using equal-frequency bins. Bin edges vary between sessions.
4. **Whisker ME camera**: Left camera preferred, right camera as fallback. Different cameras have different resolutions (left: 1280x1024@60Hz, right: 640x512@150Hz)
